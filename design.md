# Industrial Precision Design System

This document outlines the visual identity and design tokens for WEMISI.

## Colors
- **Primary Slate**: `#1a1c1e`
- **Industrial Orange**: `#f15a24` (Accents, active items, hover states, CTA highlighting)
- **Light Gray**: `#f8f9fa` (Backgrounds, layout division)
- **High-contrast Borders**: `#e2e8f0` or `#ccc`

## Typography
- **Primary Font**: `Outfit`, sans-serif
- **Scale**:
  - H1 / Display Headings: Bold, clean hierarchy
  - Legible body text

## Spacing & Layout
- **Mobile Gutter**: 16px
- **Desktop Container**: Center-aligned, max-width `1280px`
